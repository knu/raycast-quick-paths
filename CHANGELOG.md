# Quick Paths Changelog

## [1.0.2] - 2026-10-11

### Changed

- Update the Raycast and Vicinae SDKs and supporting tools.
- Update or remove dependencies affected by 24 Dependabot alerts (18 high and 6 moderate).
- Update four GitHub Actions used to build and publish both launcher archives.
- Automatically queue approved Dependabot PRs after successful CI with Mergify.
- Clarify the one-time Raycast registration and mise installation steps.

## [1.0.0] - {PR_MERGE_DATE}

### Added

- Initial release
- Quick access to favorite file paths from a searchable catalog
- Transition to Search Files with selected path (Enter)
- Paste paths into frontmost application (Shift+Enter)
- Toggle between tilde and expanded formats (TAB)
- Copy paths to clipboard (both tilde and expanded formats)
- Edit, add, delete, and reorder path entries
- Support for both CSV and TSV file formats
- Auto-detection of file format
- Empty state with quick add functionality
- Configurable external catalog file or built-in management
